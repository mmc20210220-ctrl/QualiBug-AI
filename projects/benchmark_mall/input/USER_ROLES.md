# 角色权限说明

| 角色 | 权限 |
|---|---|
| buyer | 浏览商品、管理自己的购物车、下单、支付自己的订单、取消自己的待支付订单、申请自己的退款 |
| seller | 创建和修改自己负责的商品，查看商品相关订单 |
| warehouse | 查看库存、调整库存、发货 |
| finance | 查看支付流水、审批退款、查看财务报表 |
| auditor | 只读查看报表和审计日志 |
| admin | 所有权限 |

权限原则：

1. 所有后台写接口必须校验角色；
2. buyer 不能访问后台写接口；
3. auditor 不能修改任何业务数据；
4. finance 不能修改商品和库存；
5. warehouse 不能处理支付退款；
6. seller 不能修改其他 seller 的商品。
