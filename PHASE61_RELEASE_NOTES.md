# QualiBug AI Phase61 Release Notes

## Enterprise Product UI Unification

Phase61 consolidates the most common private-pilot operating surfaces into one
server-rendered enterprise product experience. It does not add React, a
component framework, a bundler, CDN dependencies or a second authorization
model.

The shared shell lives in `ai_test_asset_center/product_ui.py` and is reused by
the private pilot runtime, enterprise TestOps control plane, knowledge center,
release dashboard and multi-industry benchmark report.

## Unified Pages

- Enterprise pilot operations center: `/dashboard`
- Enterprise TestOps control center: `/control-plane`
- Enterprise business knowledge center: `/knowledge`
- Release risk dashboard: `/release`
- Multi-industry benchmark: `/benchmark`

Each page shares:

- Left-side business quality navigation and project context.
- Top controlled-runtime status.
- Consistent cards, tables, status badges, callouts and responsive layout.
- Snapshot export for the current page data.
- Product copy focused on business quality and release evidence.

## Design Principles

- Native HTML/CSS/JavaScript only.
- Presentation-only UI shell; state mutations remain in audited runtime APIs.
- Existing permission, approval, credential-reference, audit-chain and
  production-protection boundaries are preserved.
- The UI does not fabricate success states. Page data comes from project-scoped
  JSON assets and controlled APIs.
- Environment, account and setup issues stay visible as readiness findings
  instead of being promoted into false high-value business defects.

## Private Service Routes

Read-only pages and APIs:

- `GET /dashboard?project=<project>`
- `GET /control-plane?project=<project>`
- `GET /knowledge?project=<project>`
- `GET /release?project=<project>`
- `GET /benchmark?project=<project>`
- `GET /api/pilot/overview?project=<project>`
- `GET /api/pilot/tasks?project=<project>`
- `GET /api/control-plane/overview?project=<project>`
- `GET /api/knowledge/asset?project=<project>`
- `GET /api/release/dashboard?project=<project>`
- `GET /api/benchmark/report?project=<project>`

Write APIs continue to require trusted reverse-proxy identity headers:
`X-QualiBug-Actor` and `X-QualiBug-Role`.

## Verification

Release evidence is generated by:

```bash
python -m aitestops.cli verify-release
```

The verifier runs:

- Python source compilation.
- Full pytest regression suite.
- Product UI regression tests.
- Private service smoke checks for the five product pages and six read-only APIs.

The measured result is written to `PHASE61_RELEASE_MANIFEST.json`.

## Delivery Boundary

The local delivery contains source code, tests, examples, deployment templates
and documentation. Runtime outputs, logs, caches, local databases, real customer
documents, credentials, tokens and private benchmark ground truth are excluded.
