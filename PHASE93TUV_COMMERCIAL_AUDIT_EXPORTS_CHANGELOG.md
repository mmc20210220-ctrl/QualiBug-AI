# Phase93T/U/V Commercial Audit Exports Changelog

## Phase93T — Commercial Audit Export Adapters

Converts the Phase93S commercial audit event stream into customer-system import artifacts:

- `grounded_probe_commercial_audit_exports.json`
- `grounded_probe_commercial_audit_exports.md`
- `grounded_probe_commercial_audit_ledger.csv`
- `grounded_probe_jira_issue_import.json`
- `grounded_probe_linear_issue_import.json`
- `grounded_probe_reviewer_packet_export.md`

Each audit event receives a stable `external_tracking_key`. Closure claims also receive `QB-CLOSURE-*` keys so customer tracking systems can reference QualiBug closure evidence without relying on transient issue titles.

## Phase93U — Commercial Audit Export Import Gate

Adds an independent gate for generated import artifacts:

- validates required Jira fields;
- validates required Linear fields;
- validates required CSV audit ledger columns;
- blocks duplicate external tracking keys;
- blocks raw password/token/cookie/API key/secret-like leaks;
- allows safe customer-owned placeholders such as `<FILL:jira_project_key>` and `<FILL:linear_team_id>`.

New outputs:

- `grounded_probe_commercial_audit_import_gate.json`
- `grounded_probe_commercial_audit_import_gate.md`

## Phase93V — Commercial External Tracker Reconciliation

Adds a reconciliation ledger for customer import completion:

- maps Jira/Linear/CSV import rows to QualiBug audit events;
- maps closure claims to stable external tracking keys;
- supports optional customer import results containing external IDs/URLs;
- marks entries as blocked, pending customer system IDs, pending import, import failed, or reconciled.

New outputs:

- `grounded_probe_commercial_external_tracker_reconciliation.json`
- `grounded_probe_commercial_external_tracker_reconciliation.md`
