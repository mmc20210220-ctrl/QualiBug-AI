# 测试运行手册

## 1. 启动后端

```bash
cd apps/backend
npm install
npm run dev
```

## 2. 启动前端

```bash
cd apps/frontend
npm install
npm run dev
```

## 3. 推荐测试顺序

1. 先让测试引擎读取 PRD、接口文档、数据库设计、历史问题记录、UIUX 图。
2. 让引擎抽取业务对象：用户、商品、购物车、订单、支付、退款、权限。
3. 让引擎生成场景：正常链路、边界链路、异常链路、并发链路、移动端链路。
4. 运行接口测试、页面测试、静态扫描、数据一致性分析。
5. 汇总问题时按“业务影响”而不是按代码位置排序。

## 4. 建议关注点

- 商品状态与搜索结果是否一致。
- 购物车数量、库存、价格是否按 PRD 处理。
- 订单状态是否符合状态机。
- 支付回调是否幂等。
- 退款权限、金额上限、状态条件是否正确。
- 后台接口是否正确隔离普通用户和管理员。
- 前端移动端、无障碍、兼容性是否满足设计系统。
- 数据库字段约束和索引是否支撑业务要求。
