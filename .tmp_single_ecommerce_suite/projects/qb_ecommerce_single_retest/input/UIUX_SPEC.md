# UI/UX 设计说明

## 页面清单

| 页面 | 目标 | 关键检查点 |
|---|---|---|
| 首页/商品列表 | 快速发现商品 | 首屏加载、筛选、排序、移动端布局 |
| 商品详情 | 理解商品并加购 | 图片、价格、库存、SKU、评价、到货提醒 |
| 购物车 | 修改数量和优惠 | 数量边界、优惠计算、库存提醒 |
| 结算页 | 提交订单 | 地址、金额明细、支付入口、错误提示 |
| 订单页 | 查看订单状态 | 状态流转、售后入口、物流信息 |
| 管理后台 | 商品/订单/售后处理 | 权限、审计日志、批量操作 |

## 交互原则

- 所有可点击元素需要明确状态。
- 颜色不能作为唯一信息表达。
- 移动端不应出现横向滚动。
- 错误提示应靠近触发控件。
- 支付/提交类按钮必须防重复点击。
- 图片需要替代文本。
- 表单需要键盘可操作。
- 价格、库存、优惠需要实时同步。
