# 设计系统说明

## 颜色

| Token | 用途 |
|---|---|
| primary | 主按钮、关键操作 |
| danger | 删除、退款、取消订单 |
| warning | 库存不足、支付异常 |
| success | 支付成功、订单完成 |
| neutral | 背景、边框、说明文字 |

## 字体与布局

- 桌面端最大内容宽度：1180px。
- 商品卡片桌面端 4 列，平板 2 列，移动端 1 列。
- 价格必须使用统一组件，展示“原价、会员价、优惠后价格”。
- 操作按钮必须具备 hover、disabled、loading 三种状态。
- 后台表格需要支持键盘导航和批量操作。

## 无障碍要求

- 图片必须有能表达业务含义的 alt。
- 表单 input 必须有关联 label。
- 所有弹窗支持 ESC 关闭。
- 颜色对比度满足 WCAG AA。
- 不能只依赖颜色表达错误。
