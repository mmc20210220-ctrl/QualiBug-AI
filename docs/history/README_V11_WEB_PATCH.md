# V11 Web Platform Patch

覆盖到 AI Test Asset Center V11 项目根目录后运行：

```powershell
.\RUN_OPEN_PLATFORM.cmd
```

或：

```powershell
.\RUN_WEB.cmd
```

浏览器打开 http://127.0.0.1:7860 后，点击 “V11 远程被测系统”。

输入目录固定为：

```text
platform_inputs\enterprise_shop
```

输出目录固定为：

```text
platform_outputs\enterprise_shop
platform_workspace\enterprise_shop
```
