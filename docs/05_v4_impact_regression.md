# V4 Git Diff 影响面分析与精准回归

V4 的目标不是再增加更多自动化用例，而是减少每次发版必须执行的回归范围。

流程：

```text
Git Diff
  ↓
解析变更文件、代码片段、关键词、接口路径
  ↓
匹配 OpenAPI 资产和已有测试用例
  ↓
推荐最小回归集
  ↓
生成 regression_plan + 可执行 Pytest
```

企业价值：

- 减少无效全量回归
- 缩短 CI 时间
- 让 QA 不再人工判断每次变更要测哪些接口
- 形成“变更 → 影响面 → 测试集 → 执行报告”的闭环

控制策略：

- 有明确命中时执行影响接口相关用例
- 始终保留 `/health` 冒烟
- 低置信度时执行 P0 用例或建议人工复核
- 输出 `impact_plan.json` 和 `impact_report.md` 方便审计
