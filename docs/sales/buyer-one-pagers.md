# 双买家材料 + Champion 弹药库

> 用途：一次 Pilot 会议必须同时打两类角色——技术买家（证明"真能找到"）和经济买家（证明"买得值"）。两套材料各一页，champion 弹药用于"你不在场的会议"。

---

## A. 技术买家版一页纸（给测试负责人 / CTO / 架构师）

### 标题：AI 自主检测，找到的不是告警，是带证据的真实缺陷

**它和传统工具的区别（一句话）**：不扫代码、不写脚本、不用维护用例——接入系统地址，AI 自己认知业务、自己构造数据、自己找缺陷，每条结论附完整证据链。

**三个可信点**：
1. **证据链可复核**：每个缺陷 = 请求/响应/前后状态/复现步骤，你的团队可以逐条人工验证，不是黑盒打分。
2. **诚实的成绩**：存疑发现单独标注、不计入成绩；误报率公开。我们不凑数。
3. **安全可控**：只打非生产环境；每次写操作走治理沙箱，前后观测 + 反向清理 + 审计回执；只读总开关随时可切。

**覆盖面**：14+ 类全谱系缺陷（逻辑/并发/越权/状态机/数据一致性……）、10 类 UI/UX、9 种文档格式解析、移动端 App 检测。

**实测战绩**：标准基准环境 13 分 42 秒发现 59 个缺陷（9 P0 / 33 P1），全程无人干预。

**接入成本**：一个非生产系统地址 + 一个测试账号，当天出首份报告。

---

## B. 经济买家版一页纸（给老板 / CFO / 采购）

### 标题：一名测试工程师 1/3 的成本，换一个 7×24 小时不休息的 AI 测试团队

**算账（以年计）**：

| 项 | 数值 |
|---|---|
| 中级测试工程师年综合成本（薪资+社保+管理摊销） | ¥30–50 万 |
| 一个 P0 缺陷逃逸到生产的平均损失（故障处理+客户赔偿+商誉） | ¥10 万+ / 次 |
| QualiBug 企业版年费 | 【按定价模型填，约为工程师成本 1/3–1/2】 |
| 投资回收期 | 拦截 1–2 次 P0 逃逸即回本 |

**你买到的不是工具，是三件事**：
1. **成本**：替代 90% 重复性测试劳动，现有团队聚焦业务判断；
2. **风险**：发布门禁拦截高危缺陷，少一次生产事故就是几十万；
3. **速度**：回归从"人天"变"分钟"，发版节奏不再被测试卡住。

**风险控制**：POC 先行，签字的量化成功标准，不达标不付费（或 POC 费全额退/抵）。

## C. Champion 弹药清单（给客户内部最挺你的人）

成交发生在"你不在场的会议"。以下材料打包发给 champion：

| # | 弹药 | 用途 |
|---|---|---|
| C1 | 可转发的价值报告（免登录只读链接） | 他转发给老板/同行，一次转发就是一次内部推销 |
| C2 | 《给管理层的 5 分钟汇报》PPT 大纲（5 页：问题→发现→证据→算账→建议） | 他上台汇报时直接用 |
| C3 | 竞品对比一页纸（vs 传统自动化 / vs 人工测试 / vs 安全扫描器） | 回应"为什么不用 X" |
| C4 | 异议应答速查卡（`objection-handling.md` 的客户可读版） | 他被挑战时不冷场 |
| C5 | POC 成功标准协议草稿 | 他推动立项时直接可用 |

**使用要点**：弹药全部用客户自己的 POC 数据填充（缺陷数、截图、折算金额），不用通用模板数字——自己系统的真实缺陷比任何广告语都有说服力。
