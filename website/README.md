# QualiBug AI 官网

单文件营销站点：[`index.html`](index.html)。零依赖、零外部请求，直接放到任何静态托管即可。

## 本地预览

```bash
python -m http.server 5199 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:5199/`。站点与产品运行时完全无关，不占用 `5174` / `8088`。

## 部署

把 `index.html` 作为站点根文件上传即可（Nginx / 对象存储 / CDN / GitHub Pages 均可）。

- 无构建步骤，无 npm 依赖
- 无外部 CDN、字体或分析脚本请求（离线可完整渲染）
- favicon 以 data URI 内联，字体使用系统字体栈

## 内容口径约束（改文案前必读）

本站文案受 [`AGENTS.md`](../AGENTS.md) 的 **Brand Direction Contract** 与
**Discovery Harness Evolution Contract** 约束。以下几条是硬约束，不是风格偏好：

1. **不得编造外部质量指标。** 召回率、精确率、跨行业泛化结论在拿到可验证的外部评测回执之前，
   必须保持 `NOT_MEASURED`。内部候选数 / 确认数 / 漏斗计数不得被包装成召回率或商业能力。
   「07 能力边界与口径」一节就是这条约束的直接体现。
2. **不得把「路线图」的观测面描述为已支持。** UI、数据库、消息链、性能 / 兼容性 / 稳定性类缺陷
   当前在观测层不可达；这些面上没有结果只代表未覆盖，不代表目标系统干净。
   措辞用「本版覆盖范围 / 路线图」而不是「建设中」——事实不变，但产品不能被写成半成品。
3. **不得使用昆虫 / 爬虫 / 蛛网 / 抓取语义**，也不得把雷达环、旋转扫描扇形作为主视觉。
   `Bug` 在产品语义中指「观察到的行为与期望行为之间可证据化复现的偏差」。
4. **行业中立。** 制造业 ERP / MES / WMS 只能作为滩头市场表述，不能写成产品边界。
5. **不得使用虚构的客户案例、logo 或推荐语。** 本站当前不含任何此类内容。

## 视觉与技术实现

- **品牌标识**：内联 SVG，几何直接取自 `frontend/src/brand/behavior-field-brand.json`
  的 `compact` 变体（dark 色板），与产品内 `BrandLogo` 同源。
- **色板**：Space Navy `#06101E` / System Blue `#2563EB` / Trajectory Cyan `#0EA5E9` /
  State Teal `#2DD4BF`，与品牌契约一致；青绿作为有界信号色，不做大面积色块。
- **Hero 3D 场景**：Canvas 2D 上的真透视投影（绕 Y 偏航 + 绕 X 俯仰 + 透视除法 + 景深衰减），
  三层确定性平面 —— 运行时事实层 / 行为空间层 / 业务不变量层，中层承载状态节点与一条观测轨迹，
  层间连线表示同一坐标的映射。**几何全部为常量，无随机粒子、无粒子连线、无雷达环、无扫描扇形。**
- **装饰边界**：场景 `aria-hidden`，并标注 `decorative · 示意`。
  它不表示任何真实系统、服务、模型或评测状态，这是品牌契约的强制要求。
- **动效降级**：`prefers-reduced-motion: reduce` 下渲染单帧静态场景并关闭全部入场动画；
  卡片 3D 倾斜仅在 `(hover: hover) and (pointer: fine)` 的设备上启用。
- **健壮性（三层兜底，改动这段前先读完）**：入场动效绝不能让内容永久停在 `opacity:0`。
  1. `IntersectionObserver` 负责正常滚动下的逐个显形；
  2. 若观察器**整体**未触发（后台标签页、无合成帧、被扩展拦截），1.8s 后强制全部显形；
  3. 若观察器**漏掉个别元素**（瞬时跳底、`#hash` 直达、超快滚动 —— 这三种已实测会让
     `IntersectionObserver` 整段跳过元素），滚动时节流补扫、停止后按 150 / 450 / 1000ms
     阶梯补扫，并在支持的浏览器上监听 `scrollend`。

  测量口径提醒：页面开了 `scroll-behavior:smooth`，用脚本连续 `scrollTo` 时动画会持续
  在途。**必须等 `scrollY` 真正停稳再断言**，否则会把「正在入场的元素」误判成「卡住的元素」
  —— 本项目在调试过程中就踩过这个坑，一度以为结尾 CTA 有 2/30 的概率不可见，
  实为测试在动画途中采样。等停稳后 30 次压测全清。
- Canvas 通过 `ResizeObserver` 跟随容器宽度重算，按 devicePixelRatio 渲染；
  滚出视口或标签页隐藏时 `cancelAnimationFrame` 真正停机（实测离屏 0 帧）。

## 数据出网边界（改文案时不要动这一段的口径）

站点第 06 节有一个专门的「数据出网边界」告知块，以及 FAQ 里对应的一条。它存在的原因是：

- 产品**部署**是私有化的（服务与数据落地在企业内网），但产品的发现能力依赖大模型推理；
- 仓库的默认配置 `.env.local.example` 指向 `https://api.deepseek.com/v1`（第三方 SaaS），
  `ai_test_asset_center/discovery_engine/_engine.py` 在构造时无条件创建 LLM 客户端，
  而 `deploy/private.env.example` 里没有任何 LLM 配置项；
- 因此在**默认配置下，送去推理的企业资料内容会离开企业网络**。

所以站点上**不得**出现「数据不出企业网」这类无条件的数据驻留承诺。
私有化**部署** ≠ 私有化**数据流**，两者必须分开表述。这是采购与合规的硬门槛，
写错一次就足以让客户的安全团队否掉整个方案。

## 商业表述的三条禁区（改文案前必读）

这三条不是风格偏好，是定位问题，写错会直接影响成交：

1. **不写以「周」为单位的实施周期。** 「约 2 周」「约 4–8 周」这类表述是乙方人力项目的话术，
   会把标准产品框进按人天计费的实施赛道。合作模式一栏描述的是**范围**（不接入生产 / 企业内网 /
   多系统多租户），不是**工期**。
2. **不把产品说成长期处于试用或建设状态。** 不写「尚未进入规模化客户 POC 阶段」，
   不用「建设中」标注观测面。同样的事实用**版本覆盖范围 + 路线图**表述：
   「本版已覆盖 X，Y 在路线图上」是正常的产品范围声明，「还在建」不是。
3. **承诺只能指向产品自身的行为，不能指向客户系统的结果。**
   「生产环境写操作一律 fail-closed」「内部计数永远不作为商业指标对外报出」这类可以写——
   代码里确实这么执行。但「上线之后不会有意外」这类不能写：产品从不声称能找全所有缺陷，
   多个观测面尚未纳入覆盖，一旦客户出生产事故，这句话就是把柄。
   同类表述改为限定在交付口径上，例如「口径写在合同前，不在验收后」。
4. **不向采购方暴露环境变量名、回环地址、健康检查端点。** 客户关心「有没有全局停写开关」，
   不关心它叫 `QUALIBUG_DISABLE_SANDBOX_WRITE`。技术细节留给交付文档和运维手册。

注意第 2 条与「不得夸大能力」并不冲突：措辞可以自信，事实必须准确。
「路线图」和「建设中」陈述的是同一个事实——那些观测面当前不可交付。


## 官网与交付文档的分工（防止官网随版本腐化）

官网只承载**不随版本变化**的内容：能力体系、方法论、治理与口径原则。
随版本变化的内容——各观测面的当期覆盖矩阵、指标测量状态——**只放交付文档**，
官网用一句固定的话指向它：「各观测面的当期覆盖矩阵随交付文档提供，在技术评估中逐项确认」。

交付与接入形态同理：官网的固定表述是「私有化部署是当前主力交付形态；SaaS、API、CLI、
Agent-to-Agent 等接入形态沿产品路线逐步开放，当期可用形态以交付文档为准」。
这句话在任何形态上线前后都成立——SaaS 或 API 开放时，改交付文档即可，官网不动。

因此产品能力扩展（新观测面上线、新缺陷类型落地、新接入形态开放）**不需要**更新官网；
只有定位、方法论或口径原则变化时才需要动官网。

第 07 节的十类缺陷是稳定的业务性质族（授权 / 隔离 / 状态 / 守恒 / 幂等 / 并发 / 校验 /
可见性 / 时序 / 隐私），不是版本快照，可长期保留；「开放的缺陷类型体系」一段直接取自
AGENTS.md 品牌契约（缺陷类型是开放集、发现由业务不变量驱动、不受固定检测器清单限制），
同样不随版本变化。


## 设计系统 token（深审后确立，改样式前先看）

多轮迭代曾让同一语义角色散落出 12 种正文字号、4 种悬停位移、5 种圆角。已收敛为 token，
新增样式请复用，不要再写字面值：

| Token | 值 | 用途 |
|---|---|---|
| `--fs-body` | `.92rem` | 卡片正文 |
| `--fs-body-s` | `.86rem` | 密集 / 次级正文、内联代码 |
| `--fs-caption` | `.78rem` | 微型说明 |
| `--lift` | `-3px` | 标准卡片悬停位移（`.plan` 例外用 `-4px`，主推档位刻意更强） |
| `--r-s` / `--r-chip` / `--r-m` / `--r-l` | 8 / 10 / 14 / 20px | 徽标 / 小胶囊 / 卡片 / 大容器 |

两条必须记住的坑：

1. **`.reveal` 与卡片过渡会互相覆盖。** 二者特异性同为 `(0,1,0)`，且几乎每个卡片同时带
   `.reveal`。入场用独立的 `translate` 属性（不是 `transform`），卡片过渡块必须排在 `.reveal`
   之后，并且 `.reveal.in{transition-delay:0s}` 必须保留——否则入场的交错延迟会一直作用在
   hover 与指针倾斜上，让部分卡片慢 60–240ms 才响应。
2. **中文段落不要在源码里换行。** HTML 会把换行折叠成一个空格，中文之间就会多出可见空隙。
   一句中文写在一行；确需折行时只在标签边界或 ASCII 处断开。

## 无脚本兜底

`<head>` 里有 `<noscript><style>.reveal{opacity:1!important;translate:none!important}</style></noscript>`。
没有它，脚本被 CSP 拦截或用户禁用 JS 时，全站 97 个 `.reveal` 元素会永久停在 `opacity:0`——
整页空白。改动入场动效时不要删掉这一段。
