# QualiBug AI · Phase56 Release Notes

## Evidence-backed Business Quality Assurance Coverage

Phase56 makes the quality-assurance promise measurable.

- Derives assurance units from PRD rules, OpenAPI operations and approved confirmed-Bug regressions.
- Maps each unit to modelled business failure modes instead of relying on a static Bug checklist.
- Evaluates whether current Oracle/probe families can kill each modelled failure.
- Converts surviving mutations into governed `assurance_coverage_gap` candidates.
- Adds an assurance score, critical-path coverage, PRD rule coverage, regression protection and claim guard.
- Sends no production write request and never injects faults into the SUT.
- Prevents unsupported marketing claims such as zero-defect guarantees or all-Bug coverage.
