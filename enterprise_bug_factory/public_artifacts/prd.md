# Enterprise Bug Factory Shop PRD

目标系统覆盖用户权限、电商订单、商品库存、购物车、优惠券、支付、退款、管理后台、多租户隔离和幂等控制。

核心业务规则：
- 普通用户不得访问管理员接口，未登录用户不得访问受保护接口，锁定账号不得登录。
- 用户只能查看、取消和退款自己的订单，租户之间必须隔离数据。
- 创建订单必须校验库存，成功后扣减库存；取消和退款后需要恢复状态和库存。
- 优惠券必须校验归属、有效期、使用次数和最低门槛，优惠金额不能超过订单金额。
- 支付金额必须等于订单应付金额，已取消订单不能支付，支付回调必须幂等。
- 退款只能针对已支付订单，不能重复退款，退款金额不能超过已支付金额。
