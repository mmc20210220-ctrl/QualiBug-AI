# Round 5: Dashboard — 展示真价值，不是假指标

## 问题
前端 Dashboard 已存在但只展示 scan 级别的数据。现在 Round 1-4 产生了真实数据（benchmark 指标、gap 状态、learning 生成统计、Oracle DSL 覆盖），需要把这些数据接入 Dashboard。

## 方案（轻量、数据驱动）

### 1. 后端：统一 Summary API
新建 `ai_test_asset_center/rounds_summary.py`：
- **`build_rounds_summary(project, root)`** → 聚合 Round 1-4 数据
  - Round 1: 从 `platform_outputs/{project}/benchmark/benchmark_metrics.json` 读取最新指标
  - Round 2: 从 `GapTracker` 读取当前 open/resolved/blocked gap 统计
  - Round 3: 从 `platform_outputs/_learning/` 读取最新 learning manifest 统计
  - Round 4: 从 `RuleLibrary` 统计 DSL 规则覆盖
- 返回统一 JSON，无 HTML 美化

### 2. 后端：接入 Command Center
修改 `private_pilot_service.py` 的 `_build_command_center()`：
- 在 `scan_meta` 下新增 `rounds_summary` 字段
- 已有 `benchmark_metrics` 字段保留（Round 1）
- 新增 `gap_summary`（Round 2）、`learning_summary`（Round 3）、`dsl_summary`（Round 4）

### 3. 前端：最小化展示
修改 `frontend/src/pages/Dashboard.tsx`：
- 在 Benchmark 卡片区域下方新增一行 "Rounds Overview" 卡片
- 每张卡片显示一个 Round 的核心数据（纯数字，不美化）
- Round 1: Recall / Precision / F1
- Round 2: Open Gaps / Resolved Gaps
- Round 3: Generated Probes / Oracles / Fixtures
- Round 4: DSL Rules Active / Industries Covered

### 设计原则
1. 只展示有数据的卡片（无数据不显示，不造假）
2. 纯数字驱动，不做 HTML/CSS 美化
3. 复用现有 API 结构（command center envelope）
