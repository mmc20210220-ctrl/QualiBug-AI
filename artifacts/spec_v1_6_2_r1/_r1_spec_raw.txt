11. Phase 3：Finalizer激活时机
11.1 不允许过早Finalization

Finalizer不能在以下时点派生最终终态：

业务Operation刚结束
Oracle刚结束
Cleanup尚未执行
Restoration尚未验证

可以生成中间状态Receipt，但不能生成最终TRUE_COMPLETED。

11.2 唯一最终激活时点

最终Finalizer必须在：

Business Steps Terminated
AND Oracle Phase Terminated
AND Cleanup Phase Terminated
AND Environment Restoration Phase Terminated

之后执行。

正确顺序：

Execute Business Steps
→ Oracle
→ Cleanup
→ Cleanup Verification
→ Environment Restoration
→ Build Execution Receipt Bundle
→ Validate Bundle
→ Generate Finalization Receipt
→ Derive Terminal Status
→ Generate Report Metric Receipts
