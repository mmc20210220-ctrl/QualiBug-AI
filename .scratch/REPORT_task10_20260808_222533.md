## 1. 分级规则表（通用机制，无行业/基准硬编码）

分级依据全部来自运行时编译字段的组合：`risk_family`（断言族）+ `category`（断言类别）+ `actual/expected` 违反形态（布尔访问旗标、嵌套负值、effect_count、HTTP method/path）。规则表声明在 `finding_risk_grading.py:_SEVERITY_RULES`，**首个命中生效、按优先级降序**。

### severity 规则（first-match wins）

| 优先级 | 形态（risk_family + category + actual/expected 组合） | 等级 | 规则名 |
|---|---|---|---|
| 1 | 资金/守恒族（conservation/money/finance/balance/fund/ledger/inventory…）或 category 含 non_negative/negative/conservation/money，且 actual 递归含负数值 | **critical** | money_conservation_negative |
| 2 | risk_family=authorization 且 path 含 `/auth/` + 后门关键词（debug/backdoor/bypass/impersonate/master-token/channel-test），且 actual 显示访问被授予 | **critical** | auth_bypass_backdoor |
| 3 | 访问族（authorization/isolation/tenant_isolation/ownership/permission…）+ DELETE 或 actual 含删除信号（deleted/removed/destroyed…），且 effect>0 而 expected effect=0（删除他人数据已证） | **critical** | destruction_of_others_data |
| 4 | 访问族 + actual 的 viewer_can_access==true 或 leak_detected==true（越权/跨租户数据暴露、权限提升） | **high** | cross_tenant_exposure |
| 5 | validation/input/parameter/schema/state/idempotency 族，或 category ∈ {validation_rejection, parameter_boundary, idempotency, state_machine, state_transition, http_status_class, status_class, …}（校验缺失/参数边界/状态机非法迁移/状态码不符） | **medium** | validation_parameter_state |
| 6 | visibility/display/ui/copy/presentation/i18n/wording 族，或 description 含「文字状态/文案/操作入口/提示/展示」等关键词（仅展示/文案类） | **low** | display_copy |
| 默认 | 已确认违反但族/形态未命中任何规则 | **medium** | default_unclassified |

边界语义：
- 越权 DELETE 但未观察到 effect（run3 的 9 条 DELETE finding effect=0）→ **high**（越权），不升 critical（删除未证）。
- 同 path 跨族不串级：`/api/auth/debug/token` 仅 authorization 族 3 条判 critical；visibility/validation/isolation 族同 path 各按本族规则。
- visibility 族虽 actual 带 leak 旗标（typed assertion 通用旗标），按「族+形态组合」语义归**低危**（源规则为状态文字/操作入口展示类）。

### confidence 规则（证据链完整度 → 0..0.97，动态）

| 信号 | 加分 | 判定 |
|---|---|---|
| 复现成功 | +0.30 | reproduction_steps 非空 + raw_evidence.has_real_evidence + 响应已捕获 |
| 对照双组证据 | +0.20 | evidence/observations.control_succeeded 或 authorization_causality_receipt.control_target_reached 或 raw_evidence.control_actor |
| 清理完整 | +0.10 | cleanup_failures==0 且 cleanup_status 非 FAILED/BLOCKED/PENDING |
| 独立验证 | +0.10 | gate_passed==true + SEMANTIC_CONFIRMED + VALIDATED |
| 观察者深度 | +0.05 | failed_assertions/contract receipts 的 observer_receipt_ids ≥ 2 |
| 多次 occurrence | +0.20（≥3）/ +0.10（==2）/ +0.00（1） | delivery_occurrence_count（缺省按 1） |

- **无复现（核心证据链缺环）封顶 0.50** → low；0.55–0.84 → medium；≥0.85 → high。
- 复现成功但单次 occurrence 或证据部分缺失 → 0.55–0.75 → medium；复现+清理+对照+验证+多 occurrence → 0.85–0.95 → high。
